ติดตั้ง Yoddoy Helper บนเครื่องนี้ (ครั้งเดียว)

ตัวช่วยนี้ทำให้ ไลฟ์ไปทุกแพลตฟอร์ม และ สะท้อนจอ iPhone (AirPlay) ได้ — ภาพ ฟิลเตอร์ และการจัดวางใช้ได้เลยโดยไม่ต้องติดตั้ง

  1. ⬇ ดาวน์โหลด Yoddoy Helper (Windows)
  2. แตกไฟล์ zip → ดับเบิลคลิก YoddoyHelper.bat
  3. ถ้า Windows ถามเรื่อง Firewall ให้กด อนุญาต (ติ๊ก Private network)
  4. กลับมาที่หน้านี้ — ระบบจะเชื่อมต่อให้อัตโนมัติ

อยากให้เปิดเองทุกครั้งที่เปิดคอม: ดับเบิลคลิก install-autostart.bat ในโฟลเดอร์เดียวกัน · ใช้ได้กับ Chrome และ Edge

มี Yoddoy Helper เวอร์ชันใหม่ (แก้ไลฟ์หลุด + ตั้งค่าดีเลย์)

เครื่องนี้ใช้เวอร์ชัน — ปิดหน้าต่าง Yoddoy Helper เดิม แล้วดาวน์โหลดตัวใหม่มาแตกไฟล์ทับ/แทนที่ แล้วเปิด YoddoyHelper.bat อีกครั้ง

เลือกแหล่งภาพด้านล่าง
จอ iPhone: สะท้อนหน้าจอไปที่ PC-Mirror ก่อน แล้วเลือกหน้าต่าง UxPlay

ส่งภาพเข้า TikTok LIVE Studio ไม่ต้องใช้ Stream Key

  1. กดปุ่มด้านบน → จะมีหน้าต่าง Yoddoy Output ที่มีแต่ภาพ (ไม่มีปุ่ม/กรอบ) — อย่าย่อหน้าต่างนี้ (ให้วางไว้ด้านหลังหรือจอที่สองได้)
  2. TikTok LIVE Studio → เพิ่มแหล่งที่มา → จับภาพหน้าต่าง (Window capture) → เลือก Yoddoy Output
  3. ถ้าติดแถบด้านบนของหน้าต่างมา: ใน LIVE Studio ลากขอบภาพเพื่อครอป หรือขยายภาพให้เกินกรอบเล็กน้อย
  4. เสียง: ตั้งไมค์/เสียงระบบใน LIVE Studio (ภาพจากหน้าต่างไม่มีเสียงติดไปด้วย)
